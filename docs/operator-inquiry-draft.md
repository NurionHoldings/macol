# 이동통신사 기술 실증 협의 요청 초안 — 미발송

대상: 국내 이동통신사 기업 신사업·IMS/VoLTE/VoNR 기술 담당부서

제목: MACOL 010 일반통화 중 발신자 기본 전화 화면 자동 표시 기술 실증 협의

안녕하세요. 누리온홀딩스는 개인이 자신의 010 번호에 웹 기반 전화응대 화면을 등록하고, 다른 사람이 기본 전화 앱에서 해당 번호로 발신하면 **발신자 추가 설치·권한 설정·문자 링크 터치 없이** 통화 중 화면이 자동 표시되는 ‘마컬(MACOL)’을 개발 중입니다.

첫 단계에서는 음성통화를 기존 이동통신망 그대로 유지하면서, 발신자 기본 통화 화면에 등록된 개인의 간단한 응대 화면이 나타나는지만 검증하고자 합니다. 메뉴 동기화·주문·결제는 첫 시험 범위에 넣지 않습니다. 일반 010 음성통화는 시험 기기에서 정상이나, 현재 웹 서버 단독으로는 발신자 전화 UI에 화면을 표시할 수 없습니다.

귀사의 국내 상용망 또는 시험망에서 다음 항목의 기술 실증이 가능한지 확인을 요청드립니다.

1. IMS Data Channel/5G New Calling, 기본 전화 앱 UI 연동 또는 동등한 기술로, 발신자가 별도 앱을 설치하지 않아도 등록된 010 수신번호에 발신할 때 응대 화면을 자동 표시할 수 있는지.
2. 발신·수신 회선이 서로 다른 통신사인 경우에도 동작하는지, 지원 Android 제조사·기종·OS·음성망(VoLTE/VoNR/와이파이 통화)의 범위가 무엇인지.
3. 자사 서버가 수신번호의 템플릿을 제공할 때 필요한 번호 소유 확인, 통화 이벤트/세션 API, 콘텐츠 형식, 인증 및 기술 테스트 환경의 요건.
4. 무설치·무터치 조건이 충족되지 않는 단말이 있다면 그 범위와 원인, 기술 로드맵.
5. 귀사의 담당 기술 조직과 시험 SIM/번호, PoC 협의 절차 및 예상 비용.

저희가 보유한 화면 서버 초안과 [기술 실증 요청서](operator-native-pilot-rfc.md)를 바탕으로, 양측이 지원하는 최소 인터페이스를 협의하고 싶습니다. 우선 공개 가능한 기술 지원 범위와 적절한 담당 창구를 안내받을 수 있을까요?
