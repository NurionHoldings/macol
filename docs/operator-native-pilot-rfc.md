# MACOL Native Calling Gateway — 통신사 기술 실증 요청서 v0.1

상태: 검토용 제안. 통신사·단말 OEM 승인이나 지원을 받은 문서가 아니다. 이 문서와 함께 실제 개인번호·시험 SIM 식별자·운영 비밀키를 공개 저장소에 남기지 않는다.

## 단일 성공 조건

발신자가 마컬 앱 설치·권한 설정·문자/알림 터치 없이 기본 전화 앱으로 등록된 010 번호에 건다. 기존 음성통화가 연결되면서 발신자 기본 전화 화면에 수신자의 웹 기반 응대 화면이 자동으로 나타난다. 최초 PoC는 **화면 표시만** 검증하고 양방향 메뉴는 후속 단계로 둔다.

## 검토할 네트워크 경로

**IMS Data Channel / 5G New Calling 기반 네이티브 화면**: 기본 통화 화면이 IMS 데이터 채널을 통해 사업자 허용 콘텐츠를 렌더링할 수 있는지 확인한다. GSMA NG.134 및 TS.66이 기술적 참조점이다. 국내 이동통신사·기기에서 기능을 실제 제공하고 외부 솔루션 접근을 허용하는지는 아직 확인되지 않았다.

**단말 기본 전화 앱 연동**: 운영체제/제조사 기본 전화 UI의 통화 중 카드 또는 웹 화면을 사업자가 등록된 번호에 한해 표시할 수 있는지 확인한다. 이미 설치된 제3자 보이는 ARS 모듈을 쓰는 방식은 커버리지 측정용으로는 유용하지만 전 발신자 무설치 조건의 충분한 증거는 아니다.

## 역할 분리

| 주체 | 제공·검증 항목 |
| --- | --- |
| 마컬 | 수신 번호 소유 확인 및 템플릿 게시, 발신 세션별 화면 주소/짧은 수명 토큰, 콘텐츠 응답, 결과 로그 |
| 이동통신사 | 010 통화 이벤트, 수신번호 매칭, 기본 통화 화면 확장/IMS DC 접속 권한, 실망 테스트와 타망 연동 |
| 단말 OEM/기본 전화 앱 | 발신자 조치 없이 통화 중 렌더링, 통화 오디오 유지, 지원 버전/기종 공개 |

## PoC 인터페이스 제안 (사업자 규격에 맞춰 변경)

1. 사업자는 등록된 수신번호에 대한 발신 이벤트에 `network_call_id`(난수/가명), `called_number`, `calling_network`, `terminal_capabilities`, `timestamp`를 서명/상호 인증 채널로 전달한다. 발신자 실번호는 최초 화면 표시만을 위해 필요하지 않다.
2. 마컬은 등록 번호와 게시 버전을 검사해 짧은 수명의 `template_ref`, 서명된 `view_token`, 콘텐츠 유형 및 만료 시각을 돌려준다. 미등록·게시 취소·만료에는 명확한 미표시 응답을 돌려준다.
3. 통신사/기본 전화 앱이 자신의 네이티브 권한으로 콘텐츠를 **발신자 조치 없이** 통화 중 렌더링한다. 렌더링 여부를 익명화된 `displayed`, `unsupported`, `blocked`, `timeout` 중 하나로 보고한다.
4. 음성통화 종료 이벤트가 도착하면 화면 세션을 닫는다. 화면 전달 실패는 전화 통화 자체를 방해하지 않는다.

통신망 테스트 없이 기존 `/integrations/dial-events` 호출만 성공해도 3단계가 이루어진 것으로 판정하지 않는다. 현재 API는 템플릿 조회 실험용이며 망/단말 인증·네이티브 화면 명령을 제공하지 않는다.

## 사업자 기술팀에 요청할 증거

1. 국내 상용망에서 발신자 사전 앱 설치 없는 기본 통화 화면/IMS DC 렌더링 지원 현황과 시험 SIM 제공 가능 여부.
2. **등록 010 번호 수신** 이벤트를 사업자 서버가 받고 콘텐츠 서버에 매칭시킬 수 있는지, 수신 번호의 통신사와 다른 발신 통신사에도 전파되는지.
3. 지원 단말 제조사·모델·OS·VoLTE/VoNR·Wi-Fi Calling·타사망 조합의 기능 매트릭스.
4. 플랫폼 사업자가 서비스 제공자로 접속할 수 있는 API/SDK, 테스트 환경, 기술·계약 담당 창구와 예상 비용.
5. 실제 단말에서 표시할 수 있는 콘텐츠 형식(HTML, 미니 앱 등), 표시 시점, 기본 전화 화면에서의 클릭/음성 병행 제한.
6. 사업자/OEM 제공 범위 밖 단말까지 100% 표시 보장이 가능한지. 불가능하면 미지원 단말과 명확한 원인 코드.

## 합격 판정표

| 시험 | 합격 |
| --- | --- |
| 미설치 Android 발신 → 등록 010 수신 | 기본 전화 화면에 자동 표시, 음성 유지 |
| 발신자가 해당 번호를 연락처에 저장 | 자동 표시, 음성 유지 |
| 통신사 조합 및 서로 다른 단말 | 목표 시장의 모든 조합에서 표시; 미지원 조합은 FAIL 기록 |
| 미등록/해지 번호, 통화 종료 | 다른 사람 템플릿 미표시, 화면 즉시 정리 |
| 앱 설치·권한·알림·SMS·클릭 필요 | 제품 조건 FAIL |
