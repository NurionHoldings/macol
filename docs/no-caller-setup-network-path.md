# 마컬 무설치 발신자 경로: 통신망·기본 통화 화면 연동 조건

2026-09-25 제품 기준: 발신자는 보통의 010 번호를 기본 전화 앱에서 누른다. 통화 이전에 마컬 앱 설치, 계정 가입, 권한 설정, 문자 링크 터치가 없어야 한다. 음성 통화는 기존 이동통신망에서 유지되고, 해당 번호의 개인 템플릿이 발신자 화면에 표시된다. 메뉴 선택이 수신자에게 동시에 전달된다.

## 현재 판정

- 발신자가 직접 설치하는 `android-caller/` 및 알림 터치는 **기술 시험 장치일 뿐 제품 달성 경로가 아니다**. 해당 APK의 빌드 성공은 제품 조건 통과가 아니다.
- 서버에 전화 이벤트 API와 공개 프로필만 배포해도 임의의 발신 단말 기본 전화 화면을 실행할 수 없다. 수신자 측 착신전환만으로도 이 화면 권한은 생기지 않는다.
- 기존 WebVoice 계열은 단말에 SDK 내장 앱이 있는 경우에 자동 팝업하며, 없으면 URL SMS를 클릭한다. 기존 앱이 우연히 설치되어 있었다면 이용자가 보이는 ARS를 따로 설치한 기억이 없을 수 있다.
- 후보는 통신사와 단말 제조사가 지원하는 기본 통화 UI 연동 또는 IMS Data Channel 기반 통화 중 웹 화면이다. GSMA는 데이터 채널을 통해 기본 통화 화면 내 웹 뷰 및 미니 프로그램을 제공하는 사례를 소개한다. **국내 두 시험 단말 및 이동통신사 조합에서 제공되는지는 미확인**이며, 공개 API 권한도 확보되지 않았다.

## 통신사·단말사 기술 실증 요청 계약

1. 수신자가 자신의 010 번호와 템플릿 URL 또는 서명된 템플릿 ID를 사업자에 등록한다. 번호 소유 증명과 해지/변경 절차를 확보한다.
2. 발신자가 등록 번호로 일반 음성통화를 시작하면 사업자/기본 전화 UI가 통화 세션 ID, 등록 수신번호, 단말 기능 지원 여부를 마컬 연동 게이트웨이에 전달한다. 실번호/발신자 식별자는 최소화하고 사업자와 계약에 따른 보호를 적용한다.
3. 게이트웨이가 등록 템플릿 버전과 당회 세션용 짧은 수명의 서명 토큰을 돌려준다. 토큰의 범위는 수신번호와 통화 세션으로 제한한다.
4. 사업자/기본 통화 UI가 음성통화를 끊지 않고 **사용자 추가 조작 없이** 템플릿을 통화 중 화면에 표시한다. 메뉴 이벤트는 통화 세션 ID와 순번으로 양측에 전달한다.
5. 통화 종료 시 화면 세션 종료 및 만료, 네트워크 단절/미지원 단말에서는 음성 통화를 정상 유지한다.

## 먼저 받아야 할 답

- 해당 국내 이동통신사에서 발신·수신 010 간 통화 중 IMS Data Channel 또는 동등한 기본 통화 화면 확장을 상용 지원하는가? 어느 단말·OS·가입자 조합인가?
- 망 사업자와 단말 제조사가 각각 제공해야 할 SDK/API, 인증, 계약, 시험 번호, 테스트 SIM, 비용은 무엇인가?
- 수신 번호 기준 URL/템플릿 조회를 발신자 기본 전화 화면에 표시할 권한과 사업자 서버의 통화 이벤트 전달 권한을 제공하는가?
- 앱 미설치·권한 미설정·문자 미터치 조건에서 실제 발신 단말 2종의 화면 표시와 메뉴 양방향 전송을 시험할 수 있는가?
- 지원하지 않는 단말의 음성만 유지할 때 지원 범위와 실패율을 어떻게 보고하는가?

## 제품 완료 기준

발신자 휴대전화 초기 상태에서 일반 010 발신 → 통화 중 자동 템플릿 표시 → 메뉴 클릭 즉시 수신자 화면 동기화 → 통화 유지. 별도 설치, 역할 전환, 알림/문자 터치가 있으면 FAIL. 실제 통신사·단말 조합에서 이 전체 흐름을 재현하기 전까지 제품 상태는 `NETWORK_INTEGRATION_BLOCKED`이다.
